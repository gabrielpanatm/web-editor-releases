# Web Editor Releases

Instalatoarele și actualizările pentru Web Editor, aplicația desktop de editare a site-urilor Astro.

[Vezi versiunile disponibile](https://github.com/gabrielpanatm/web-editor-releases/releases)

- **Windows x64** — instalatorul `.exe`
- **Mac Apple Silicon** — pachetul `mac-arm64.dmg`
- **Mac Intel** — pachetul `mac-x64.dmg`
- **Linux x64 (Debian, Ubuntu și derivate)** — pachetul `.deb`

Pachetele includ Git. Versiunile instalate caută actualizări din aplicație.
